# Math-Meme-Repair
 Fine-tuned DeepSeek-Math-7B model to fix viral math memes. Used dataset of 20 errors, few-shot prompting, and 
Gradio UI on Hugging Face Spaces. Delivered corrections with explanations steps. 

Checkout the deployed model on hugging face: https://huggingface.co/spaces/huzaifa113/Math-Meme-Repair
